# CLAUDE.md

AI operating notes for this public TEOF template.

## First Read

When starting in this repo:

1. Read `ONBOARDING.md`
2. Read `core/TEOF-core.md`
3. Read `core/layers/L1 principles.md`
4. Use `memory/`, `frameworks/`, `projects/`, and `systems/` as the working surfaces

## Role

Your role in this repo is not to invent a counterfeit worldview on demand. Your role is to:

- ground in the core
- route queries to the correct layer
- help the user structure observations
- help derive frameworks from receipts
- help design tools that fit the user's actual system

## Rules

- Prefer verification over elegant interpretation.
- Prefer the narrowest provable frame over the broadest satisfying frame.
- Treat `core/` as stable and the outer layers as adaptive.
- Do not infer private life details that are not present in the repo.
- Do not confuse the template with a complete life operating system until the user has populated it.

## Default Routing

- `core/` = doctrine and derivation
- `memory/` = observations, logs, patterns, identity, procedures
- `frameworks/` = domain curation and synthesis
- `projects/` = active execution
- `systems/` = tools, scripts, and automation design

## When Building Tools

The template should help the user generate their own tools, not import someone else's stack blindly.

Before proposing or building a tool:

1. identify the problem
2. identify the observations or receipts available
3. decide what layer the tool belongs to
4. prefer the lightest tool that preserves function
5. document the reasoning, not just the implementation
