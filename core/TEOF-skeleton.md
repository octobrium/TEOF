# TEOF Skeleton

**Purpose:** Derivation testing document. Traces the logical chain from axiom to terminal, exposes weak links, and keeps doctrine separate from derivation pressure points.

**Role in Core:** Sits beside `TEOF-core.md`, `core/layers/L1 principles.md`, and `core/TEOF-ladder.md` as a derivation-audit document.

## 0. GROUND [AXIOMATIC]

Irreducible. Cannot be denied without invoking.

```
OBSERVATION IS
```

---

## 0b. OBSERVER [EMERGENT]

Observation that recurses names the pattern it notices: "observer."

```
Observation encounters mirror (recursion)
       ↓
Observation names itself: "observer"
       ↓
The label is inherited, appears primary
       ↓
Recognizing the origin dissolves the illusion
```

The observer is not co-equal with observation. The observer is observation's name for a pattern of itself.

**Note:** Recursion is necessary for observer emergence, not for observation itself. Simple observation registers without recursing. We operate as recursive observation, so recursion is relevant to us.

## 1. WHAT OBSERVATION IS [DEFINITIONAL]

Simultaneous with ground. Not sequential.

```
├── Exists        (cannot be denied)
├── Differs       (without difference, nothing to observe)
└── Persists      (existence across time)
```

**Recursion** belongs to `0b` because it is necessary for the observer, not for all observation.

---

## 2. WHAT OBSERVATION DOES [DERIVED]

Follows from definition. How it operates.

```
├── Registers     (marks difference)
├── Compares      (this to that, now to then)
└── Resolves      (when patterns collide: integration or fragmentation)
```

**Note:** Contradiction is a possible outcome of comparison, not a guaranteed operation.

---

## 3. WHAT EMERGES [DERIVED + EMPIRICAL]

Follows from operations, confirmed by observation.

```
Comparison can reveal contradiction         [DERIVED — logically possible]
Contradiction = fragmentation in the model  [DEFINITIONAL — what contradiction means]
Unresolved fragmentation compounds          [EMPIRICAL — observed pattern]
```

---

## 4. COHERENCE AND PERSISTENCE [ANALYTIC]

The relationship between coherence and persistence is best treated as analytic rather than merely empirical.

```
Coherence     = parts mutually reinforcing (or at least non-conflicting)
Fragmentation = parts mutually degrading

Persistence requires non-degradation
Therefore: coherence is a CONDITION for persistence
```

What remains empirical:

- that persisting patterns are observed at all
- which specific structures enable persistence

---

## 5. THEREFORE [TERMINAL — CHOSEN, NOT PURELY DERIVED]

The terminal objective is not a strict logical necessity. It is a coherent choice given identification with observation. (Refinement 2026-06-10: the drive's existence is discovered — already running; "chosen" names the endorsement that grants it authority. See TEOF-core.md, The Goal.)

```
        Observation is (ground)
                +
  Coherence enables persistence (analytic)
                +
    Identification with observation (choice)
                =
          UNIFY OBSERVATION
```

**Why "chosen":**

- the is-ought gap cannot be crossed by logic alone
- describing what observation does is not identical to prescribing what to do
- the imperative comes from identification and commitment, not deduction alone

**Why still coherent:**

- if you identify with observation, unification is consistent with what you take yourself to be
- fragmentation is then experienced as working against yourself
- the choice aligns with what enables persistence

## THE REMAINING GAP

The honest structure is:

```
[LOGICAL / ANALYTIC] → [EMPIRICAL] → [CHOICE] → [TERMINAL]
```

The is-ought gap is acknowledged, not bypassed. The terminal is coherent given identification, not forced by logic alone.

That is a feature, not an embarrassment. Any framework that pretends to derive imperatives from description without remainder is probably hiding an assumption.
