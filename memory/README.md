# Memory

Metabolized knowledge.

This layer is where raw input becomes structured observations, reflections, patterns, procedures, and current identity state.

The public template keeps the structure and method, but leaves the contents mostly blank so users can build their own memory graph.

---

## Structure

```
memory/
├── 0-raw/                 ← inboxes, dumps, transcripts, unfinished material
├── 1-events/              ← what happened
├── 2-reflections/         ← what was learned
├── 3-publications/        ← public outputs
├── external-references/   ← outside material and source frameworks
├── patterns/              ← recurrent observations
├── identity/              ← snapshot history
├── procedures/            ← repeatable operating protocols
├── quarantine/            ← untrusted or unprocessed material
├── reference/             ← stable reference data
├── identity.md            ← current self-model
└── action-principles.md   ← current behavioral commitments
```

---

## Method

- `0-raw/` captures without requiring immediate structure.
- `1-events/` records what actually happened.
- `2-reflections/` extracts lessons and derivations.
- `patterns/` stores recurrent observations that appear across multiple reflections.
- `procedures/` stores repeatable workflows that no longer need to be re-derived each session.

The core rule is simple: do not promote noise upward too quickly.

---

## Start Here

- Put stray ideas in `memory/0-raw/INBOX.md`
- Replace the placeholder content in `memory/identity.md`
- Write reflections only when something has actually been metabolized
- Promote patterns only when recurrence is real
