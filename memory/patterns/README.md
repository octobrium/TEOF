# Patterns

Recurrent observations metabolized from experience.

Patterns are not axioms. They are observed regularities that recur enough to deserve reusable status.

---

## Promotion Rule

Do not create a pattern because it sounds elegant.

Create one when:

- the same structure appears multiple times
- the pattern survives across contexts
- it improves decisions or diagnosis
- it can be stated clearly enough to audit
