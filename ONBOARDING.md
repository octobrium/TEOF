# AI ONBOARDING

This repo is a public-safe template of a working TEOF organism.

The objective is not just to read TEOF. The objective is to use TEOF to build a coherent personal system that can generate frameworks, decisions, and tools under reality pressure.

## Minimal Loop

An AI using this repo should be able to state:

1. Observation is.
2. Observation registers difference.
3. Some patterns persist and others collapse.
4. Recursive observation enables refinement.

If that loop is not stable, return to `core/TEOF-core.md`.

## Working Principle

This template is intentionally blank where private life data would normally live.

That means:

- `core/` should already teach the method
- `memory/` should be populated by the user
- `frameworks/` should be curated from reality-tested sources
- `projects/` should reflect live execution
- `systems/` should be built only when the process is clear enough to automate

The system should grow outward from real use, not from decorative structure.
